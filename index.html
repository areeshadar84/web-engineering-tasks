Web Dev Day 2026

A one day event for students who want to learn how real web pages are built. Three hands-on sessions, free lunch, and a portfolio review at the end.

Saturday, 12 December 2026 | Seminar Hall B, City Tech Campus, Islamabad

Reserve your seat

About the event

Web Dev Day is organised by the Computer Science Society for first and second year students. You do not need any experience. If you can open a text editor and a browser, you can join us.

Each session is taught by a senior student or a working developer, and you will write code yourself instead of only watching slides.

What to bring

  • A laptop with VS Code installed
  • Your student card
  • A notebook and a pen
  • A charger

How to register

  1. Fill in the form at the bottom of this page
  2. Choose the sessions you want to attend
  3. Wait for the confirmation email
  4. Show the email at the entrance

Sessions

Pick one, two or all three. Each session lasts 90 minutes.

HTML Basics Workshop

Speaker: Ayesha Khan

Build your first page from a blank file. We cover headings, lists, links, images, tables and forms.

See the time

CSS Layout Lab

Speaker: Hamza Rauf

Learn the box model, Flexbox and Grid by fixing a broken page together, then make it work on a phone screen.

See the time

Portfolio Review Clinic

Speaker: Sana Iqbal

Bring a small project and get feedback on structure, spacing and readability from a working front-end developer.

See the time
